# 棋伴 Chessmate

面向初學者的西洋棋練習網站。提供響應式棋盤、本機 Stockfish AI 對戰、棋局分析與重走練習；個人化 LLM 教學尚未實作。

## 開發

需要 Node.js 22.18+（本環境使用 24）與 npm。

```sh
npm ci
npm run dev
```

開發伺服器使用 3000 埠。`postinstall` 會將固定版本 Stockfish 17.1.0 的單執行緒 lite WASM 複製到 `public/engine/`，無需 API key。瀏覽器需要支援 WebAssembly 與 Web Worker。引擎首次下載約數 MB；難度為相對強度，未校準 Elo。

## 功能

- 點選或拖曳落子、合法目的格、四種升變、將軍與終局判定。
- 執白／執黑、三段難度、AI 搜尋取消與錯誤重試。
- 悔棋回到玩家上次落子前、翻轉棋盤、逐手回放、PGN 下載。
- localStorage 保存目前棋局與設定，重整後恢復完整走法歷史。
- 三次重複局面、五十步規則採自動和棋，適用自由練習；沒有時鐘與正式競賽裁判流程。
- 新對局會取代本機紀錄；可先匯出 PGN。尚無帳號、雲端儲存或多裝置同步。
- `/review` 復盤教室：帶入目前棋局、貼上 PGN、選擇分析方、查看評分曲線與最多三個關鍵失誤。
- 先隱藏答案的重走練習；用同一搜尋預算重新比較玩家嘗試與引擎建議，接受約 0.5 分內的替代走法，將殺另行處理。
- 分析、重走與棋譜合法性皆在瀏覽器執行，無需後端引擎或 API key，不將棋譜傳送到外部服務。

## 驗證

```sh
npm test
npm run typecheck
npm run build
npm run start -- --port 3001
```

另開終端執行瀏覽器測試（針對 3001 埠的正式版）：

```sh
npx playwright install chromium
npm run test:e2e
```

若已有系統 Chromium，可使用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`。規則測試涵蓋雙方悔棋、將死、重複局面恢復、王車易位、吃過路兵、升變，以及黑白評分視角、將殺分類、候選失誤複查、替代走法與變化線驗證。瀏覽器測試會實際運行 WASM 引擎，驗證對戰、恢復、下載、分析、取消、將殺失誤、重走、引擎失敗與手機排版。

## 程式結構

- `app/chess-app.tsx`：棋局互動與響應式 UI。
- `lib/engine.ts`：Stockfish UCI Worker、搜尋預算與取消。
- `lib/game.ts`：對局狀態與悔棋。
- `scripts/copy-engine.mjs`：安裝時準備引擎靜態檔案。
- `app/review/`：PGN 匯入、分析進度、局勢曲線、關鍵時刻與重走 UI。
- `lib/analysis.ts`：合法棋譜與變化線、評分／將殺分類、候選失誤加強搜尋。
- `lib/analysis-engine.ts`：可取消、具逾時處理的 UCI 分析 Worker。

每次對戰 AI 搜尋使用獨立 Worker，悔棋或新對局會終止舊 Worker。復盤使用另一個單執行緒 Worker，離開頁面或取消時會終止並拒收過期結果。

## 分析方法與限制

- 支援標準西洋棋 PGN，包括 SetUp/FEN 自訂起始局面。上限為 32,000 字元與 240 手（120 回合）。
- 每手先用 12,000 nodes 搜尋，同一局面再以 `searchmoves` 限制玩家實際走法；兩次搜尋會清除 hash。建議走法與實際走法相同時重用結果。
- 從所選棋色的候選失誤中，依嚴重度挑最多六個，以每次 80,000 nodes 複查；只從複查結果中挑最多三個關鍵時刻。
- 分數儲存與圖表皆以白方視角呈現，失誤損失以落子者視角計算。約 100 cp 標為一般失誤、200 cp 標為重大失誤，是啟發式門檻；尚未依勝率變化、玩家程度或局勢階段校準。
- 將殺使用勝方與步數獨立表示，不當作一般分數。已被強制將殺的局面不因將殺距離不同而重複標記。
- 變化線逐步以 chess.js 驗證後呈現；說明由規則與引擎證據生成，尚未加入戰術主題分類或 LLM。
- 圖表只畫 ±8 範圍；選擇走法可查看未截斷的數值。評分不是使用者實際勝率。
- 這是有限搜尋預算的初步分析，不保證找出所有失誤。複雜局面與 lite 引擎可能有誤判；手機速度依裝置而異。
- 分析結果只保留在目前頁面，重整後須重跑。貼上 PGN 不會覆寫原本的對戰紀錄；目前不提供分析報告雲端儲存。
